# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

* Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
* 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

### 배포 링크

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
	- 일부 QR 코드 생성 사이트는 중간 페이지를 거쳐 목적지로 연결하는 방식을 사용합니다. 이러한 사이트는 일정 기간이 지나면 연결을 끊고 유료 결제를 유도하며, 이미 QR 코드를 인쇄물 등에 출력한 사용자의 상황을 이용하여 돈을 벌기도 합니다. 이러한 문제를 방지하고 안전한 QR 코드를 만들고자 하였습니다.

- 본인이 이 앱을 언제, 어떻게 사용할 건가요?

- 웹 사이트 주소를 이용하여 QR 코드 이미지 생성
	- QR 코드 이미지 테두리 색상 및 이미지 크기 설정 
- Gemini AI를 이용한 악성 사이트 검사

### AI 기능
- 어떤 AI 기능을 추가했나요?
	- Gemini AI를 이용하여 입력된 URL이 안전한지 판단하는 악성 사이트 검사 기능을 추가하였습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
	- 입력된 URL을 분석하여 단순 오타나 악성 사이트인지를 판별합니다. 이를 통해 사용자가 잘못된 주소로 QR 코드를 생성하는 것을 사전에 막아줍니다.

### 2. 프롬프트 개선 과정
- 처음 결과물의 문제점은 무엇이었나요?
	- 컬러 픽커 방식으로 하는 방법은 미세한 움직임에도 값이 많이 움직여 색을 맞추기 어려움이 많았습니다. 그래서 일치율이 100%인 색상을 거의 선택하지 못하는 문제가 있었습니다. 그래서 컬러 픽커로 시작하다가 슬라이더로도 시도해보고 결과적으로는 제시된 색상와 채도 및 명도를 선택하여 색을 맞추는 방식으로 변경하였습니다.
- 어떤 식으로 프롬프트를 수정했나요?
	- Gemini Canvas의 미리보기 기능을 통해 확인하면서 수정해야 하는 부분을 제시하고 수정 방향을 지시하였습니다. 
	- 예시 : 색에 대한 선택지를 늘리고 채도 및 명도에 대한 선택지 줄이기. 색의 경우 선택지를 늘리되 비슷한 색의 선택지가 없도록 조정. 비슷한 색이란 사람이 화면으로 구분하기 어려운 색을 뜻함. 채도 및 명도의 경우 흰색과 검은색의 가까운 선택지는 삭제.
- 몇 번의 반복을 거쳤나요?
	- 기능 수정의 경우 5번, 단순 UI 변경은 3번의 반복을 하였습니다.

### 3. 효과적이었던 프롬프팅 전략
- 어떤 방식으로 요청했을 때 원하는 결과가 나왔나요?
	- 구체적으로 지시할수록 원하는 결과가 나왔습니다. 특히 화면이 메인, 진행, 결과 등으로 나누어져 있는 경우, 어떠한 수정이 필요할 때 그냥 지시하는 것보다 어떤 화면에서 어떻게 수정해야하는지 요청할 때 효과적이였습니다.
- 반대로 효과가 없었던 방식은 어떤게 있었나요?
	- 위와 반대로 여러 화면에 걸쳐 비슷한 기능이 존재하는 경우, 구체적으로 지시하지 않고 단순하게만 요청하면 전체적인 기능이 수정되어버리는 문제가 있었습니다. 

### 4. 배운 점
- Gemini Canvas를 효과적으로 사용하기 위한 나만의 팁이 있다면?
	- 결과에 문제가 있을 경우 이전 버전으로 돌아가 이전 프롬프트보다 좀 더 구체적인 프롬프트를 작성하는 것이 효과적이였습니다.

### 5. 리뷰어에게 피드백 받고 싶은 포인트
- 프롬프트를 작성할 때 조건 1, 조건 2, 추가 1, 추가 2 이런 식으로 번호를 단순 나열하면서 제한 사항, 기능 요구, 화면 구성 등 성격이 다른 내용을 하나의 범주로 묶어 작성했습니다. 지시의 성격에 따라 구분하여 구조화하는 것이 더 나은지, 아니면 AI가 맥락에 맞게 해석하도록 두어도 괜찮은건지 고민입니다.
